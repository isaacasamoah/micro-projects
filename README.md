# Micro projects

Small experiments in AI, maths, Rust and building things with agents.
Learn something, build something small, and share what happened so we can learn
from each other.

## Projects

| Project | Question | Status |
| --- | --- | --- |
| [Kev](projects/kev/) | How do we build, train and understand a small calibrated decision model? | Planning; no model implemented yet |

Each project is self-contained: its code, dependencies, run instructions and
learning notes live in its folder. There is no repository-wide build system.
Use the [project README template](templates/README.md) when adding an experiment.

The daily aim is one hour reading and one hour building, each including
15–20 minutes for sharing. A useful result might be a few sentences, a visual,
or a demo. Larger questions can take several small sessions.
