A tiny attention-based decision network

These are actual toy computations. The animation replays them at reading speed, not measured execution speed.

Queries and matrices start hand-set. This is attention pooling plus a small classifier, not a full transformer. The output labels are fixed; they are not calibrated confidence or a safety guarantee.

Training changes only the final 3 × 3 weights and three biases. Attention and the hidden layer stay frozen. Editing their controls is a manual change, not learned training.

No model is connected to a robot. Changes stay in memory and reset on reload.
