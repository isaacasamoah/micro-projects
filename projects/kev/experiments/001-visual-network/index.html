1 / CHANGE THE EVIDENCE

Which route?

Clearance and progress are normalized features, not raw camera pixels. Each route also gets a one-hot identity.

No hard safety rule is enforced here. This is a classification example, not a robot controller.

2 / CHANGE WHAT EACH HEAD LOOKS FOR

Two views of the same input

Each head has a two-number query. Keys describe routes; values carry route identity. Queries and projections start hand-set.

These are query-to-input attention heads, not a complete transformer. Both share key/value projections in this tiny example.

3 / READ A TYPED DECISION

Decision

The final three logits correspond to a fixed enum. Softmax gives a normalized distribution; argmax chooses a label. There is no next-token loop.
A valid type does not imply a correct decision. These scores are not calibrated confidence. Ties choose the first enum member.
